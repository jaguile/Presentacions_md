## 🧠 7. Exemples pràctics

### 🧩 Escenari 1: Permisos bàsics
```bash
sudo mkdir /empresa
sudo mkdir /empresa/redaccio
sudo mkdir /empresa/revisio
sudo mkdir /empresa/direccio

sudo groupadd redaccio
sudo groupadd revisio
sudo groupadd direccio
sudo useradd -m anna -G redaccio
sudo useradd -m jordi -G revisio
sudo useradd -m marta -G direccio,redaccio
sudo useradd -m pere -G direccio
```

Permisos:
```bash
sudo chown -R root:redaccio /empresa/redaccio
sudo setfacl -m g:redaccio:rwX /empresa/redaccio

sudo chown -R root:revisio /empresa/revisio
sudo setfacl -m g:revisio:rX /empresa/revisio

sudo chown -R root:direccio /empresa/direccio
sudo setfacl -m g:direccio:rwx /empresa/direccio
```

---

### 🧩 Escenari 2: Permisos heretats (default)
```bash
sudo setfacl -m d:g:redaccio:rwX /empresa/redaccio
```

Això farà que qualsevol fitxer nou creat dins `/empresa/redaccio`
tingui automàticament permisos de lectura i escriptura per al grup `redaccio`.

---

### 🧩 Escenari 3: Consultar i provar

Comprova:
```bash
getfacl /empresa/redaccio
```

Prova amb un altre usuari:
```bash
sudo -u anna touch /empresa/redaccio/prova.txt
sudo -u jordi cat /empresa/redaccio/prova.txt
```

Si `jordi` no té permís, rebrà un error “Permission denied”.

---

## 🧹 8. Neteja final

Per eliminar totes les ACL d’una estructura:
```bash
sudo find /empresa -exec setfacl -b {} \;
```
